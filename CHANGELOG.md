# Changelog

## 1.0.0-rc.1 — November 5, 2026

First playable release candidate. Connects farming, building, production, livestock, villager work, inventory, trading, neighbor help, shared royal progression, exploration, and decoration in one estate game. Includes original environment, crop, inventory, and character animation atlases; bulk phone controls; Firebase configuration and server-validated commands; permission and concurrency tests; GitHub deployment workflows; and an explicit production-verification record.

This candidate is not promoted to final 1.0 until the live Firebase and physical-device release gates in IMPLEMENTATION.md have passed.
